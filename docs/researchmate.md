# Alur ResearchMate

ResearchMate berfokus pada proyek riset akademik. Peneliti merumuskan pertanyaan, mengumpulkan artikel dan PDF, membandingkan temuan, menilai kandidat celah riset, lalu menyusun laporan yang rujukannya dapat dibuka ulang. Konsep agen meliputi Planner, Discovery, Analysis, Synthesis, Research Gap, dan Verification.

ITS Academic saat ini menyediakan autentikasi, daftar proyek pribadi, formulir masukan, dan tinjauan rencana awal berbasis aturan. Tinjauan menerima pertanyaan riset, jumlah artikel/PDF, dan mode sumber. Pengguna dapat menyimpan rencana tersebut sebagai proyek dalam akunnya setelah memberi judul dan ringkasan, lalu membuka detailnya dari dashboard. Tombol rencana baru mengosongkan draf sesi. Hasil hanya menyarankan langkah persiapan; aplikasi ini tidak membaca isi PDF, menelusuri indeks ilmiah, menghasilkan matriks literatur otomatis, atau memanggil model bahasa. Pernyataan kandidat celah riset tetap perlu diverifikasi terhadap sumber asli.

Database PostgreSQL menyimpan pengguna, proyek, rencana riset, dan masukan. Data proyek contoh tersedia dari seeder. Pembuatan proyek melalui alur rencana riset sudah tersedia; penyuntingan proyek belum tersedia.
